# dev/launch/ — launch packs and run reports

The home for orchestrated-run records: each run gets a **launch pack** (authored from
[`process/templates/launch-pack.template.md`](../../process/templates/launch-pack.template.md))
and, at close, a **run report** (from
[`run-report.template.md`](../../process/templates/run-report.template.md)) that the pack is
stamped SPENT against. The pack is the commissioning record — what was asked, on what terms;
the report is the close record — what happened, measured independently. Neither is ever
deleted; a superseded conclusion is stamped, its wording preserved
([`process/doctrine/supersession.md`](../../process/doctrine/supersession.md)).
