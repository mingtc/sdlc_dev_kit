The example module needs no setup. A module with something to set up lists the steps here, in the order to do
them, and says how to tell each worked:

1. What to install or sign in to, and where to get it.
2. The command to run afterwards, and what it prints when it worked.

`enable` prints this file after the module's files are in place. `setup.sh` beside it is optional and does the
part a script can; the kit never runs it, so run `sh modules/example/setup.sh` yourself.
